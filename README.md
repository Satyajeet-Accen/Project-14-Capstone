# Project 14: App Deployment using EKS

## Overview
This repository contains the Terraform configuration to provision an AWS EKS cluster and the Kubernetes manifests to deploy a load-balanced application.

## Resources Provisioned
* AWS EKS Cluster (`satyajeet-eks-cluster`)
* Kubernetes Deployment (`satyajeet-app`)
* Kubernetes LoadBalancer Service (`satyajeet-service`)
